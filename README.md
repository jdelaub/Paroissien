# Paroissien

Application Android catholique romaine qui reproduit l'expérience d'un livre de prière papier : pages qui tournent, rubans de tissu, images pieuses. Elle réunit le missel, la Bible, l'Imitation de Jésus-Christ, les Exercices de saint Ignace, les lettres de Clairval, des prières et le calendrier liturgique.
